AIラベル ワンキー for X

X の投稿・返信に「AIで生成」ラベルをキー 1 つで付けます

ショートカットキー

…

使いたいキーの組み合わせを押してください（Esc でやめる）

…

初期設定は Ctrl + Shift + Y です。変えたキーは、開いている X のタブにもすぐ反映されます。

表示

うまくいかなかったときの赤いお知らせは、この設定に関係なく出ます。

使い方

  1. X で投稿欄か返信欄に文章を書く
  2. ショートカットキーを押す → 旗マーク（コンテンツ開示）→「AIで生成」をオン →「完了」まで自動で進みます
  3. カーソルは文の最後に戻るので、そのまま Ctrl + Enter で送信できます
  • すでにオンのときは何もしません（押しすぎてオフに戻ることはありません）
  • この拡張が投稿・送信をすることはありません
  • ツールバーの拡張アイコンを押しても同じ動きをします
  • マウスのボタンで使いたいときは、マウスの設定ソフト（Logi Options+ など）で、ボタンにこのキーを割り当ててください

X Corp. とは関係のない、個人が作った拡張です。データを集めたり、外に送ったりはしません。
